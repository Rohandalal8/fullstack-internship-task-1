
# Full Stack Internship - Task 1

## Fundamentals and Setup

A simple React application created using Vite
as part of my Full Stack Developer Fresher
internship.

## Technologies
- React
- JavaScript
- Vite
- Git and GitHub

## Run Locally

1. Clone this repository.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown in the terminal.

## Objective

Verify the development environment, understand
basic project structure, and practice version
control using Git and GitHub.
